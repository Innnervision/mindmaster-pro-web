# MindMaster Pro Web

MindMaster Pro is a comprehensive mental wellness and mindfulness application designed to help users improve their mental health and well-being.

## Live Demo

Visit the live application: [https://innnervision.github.io/mindmaster-pro-web/](https://innnervision.github.io/mindmaster-pro-web/)

## Features

- Meditation and mindfulness exercises
- Mental health tracking
- Stress management tools
- Personalized wellness recommendations
- Progress and goal tracking

## Technology

- Built with Flutter
- Web deployment via GitHub Pages
